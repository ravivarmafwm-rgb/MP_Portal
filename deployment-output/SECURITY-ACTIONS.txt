HOSTINGER SECURITY ACTIONS

Required runtime
- PHP 8.3+ (confirm the exact constraint in composer.json before selecting the hPanel PHP version).
- Composer 2.x for host-side dependency installation.
- PHP extensions: pdo, pdo_pgsql, mbstring, openssl, tokenizer, xml, ctype, json, fileinfo, curl, intl, and zip.

Permissions
- Directories: 755
- Files: 644
- storage/: 775 (including storage/app, storage/framework, and storage/logs)
- bootstrap/cache/: 775
- Never make .env, vendor, or configuration files world-writable.

Required production settings
- APP_ENV=production
- APP_DEBUG=false
- APP_URL=https://mpportaldashboard.focuswebmedia.in
- PostgreSQL DB_* values
- Strong APP_KEY
- Production CORS/Sanctum stateful domains and frontend API URL
- Mail, queue, cache, filesystem, and notification credentials

Safe commands (when terminal access is available)
- php artisan optimize:clear
- php artisan config:cache
- php artisan route:cache
- php artisan view:cache
- php artisan migrate --force
- composer dump-autoload -o

Storage and jobs
- No storage symlink is required by this flattened package.
- Keep storage protected by the included .htaccess; use authorized application download routes.
- Configure the Laravel scheduler cron (`php artisan schedule:run`) every minute if scheduled jobs are enabled.
- Run a queue worker for the configured driver if asynchronous notifications/jobs are enabled; supervise and restart it after deploys.

Security operations
- Force HTTPS at the domain level and enable the commented redirect block in .htaccess only if required by the host.
- Restrict database access to the hosting account and rotate credentials periodically.
- Maintain off-site backups of PostgreSQL and storage/app.
- Review upload limits, PHP error logs, failed jobs, and authentication logs after deployment.
- The package includes `.env` at the user's request. Review and rotate all credentials before upload; never expose it over HTTP. Do not upload tests, .git, node_modules, or source maps.
