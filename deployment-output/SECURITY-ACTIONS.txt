MP Constituency Management System — Hostinger/cPanel Security Actions

Runtime
- PHP 8.3+; Composer 2.x; Node.js 20 LTS only for build-time.
- PHP extensions: Ctype, cURL, DOM, Fileinfo, Filter, Hash, Mbstring, OpenSSL, PCRE, PDO, pdo_pgsql, Session, Tokenizer, XML, JSON.

Permissions
- Directories: 755.
- Files: 644.
- `mp-dashboard/storage/`: 775.
- `mp-dashboard/bootstrap/cache/`: 775.
- Never make the application root world-writable.

Required commands from `/home/USERNAME/mp-dashboard/`
- `php artisan storage:link`
- `php artisan optimize:clear`
- `php artisan config:cache`
- `php artisan route:cache`
- `php artisan view:cache`
- `php artisan optimize`
- `composer install --no-dev --optimize-autoloader`
- `php artisan migrate --force`

Scheduler/queue
- Cron every minute: `* * * * * cd /home/USERNAME/mp-dashboard && php artisan schedule:run >> /dev/null 2>&1`
- Queue worker: `php artisan queue:work --sleep=3 --tries=3 --timeout=120` under Supervisor or the hosting provider's process manager.
- Restart after deployment: `php artisan queue:restart` and restart PHP-FPM if available.

Environment
- Set `APP_ENV=production`, `APP_DEBUG=false`, `APP_KEY`, `APP_URL`, `FRONTEND_URL`, PostgreSQL `DB_*`, `SESSION_SECURE_COOKIE=true`, `SESSION_HTTP_ONLY=true`, `SANCTUM_STATEFUL_DOMAINS`, `SANCTUM_EXPIRATION`, `QUEUE_CONNECTION`, `CACHE_STORE`, `FILESYSTEM_DISK`, CORS, mail, and communication provider variables.
- Do not upload `.env`; create it on the server from `.env.example` and rotate any leaked local credentials.

Web security
- Point the domain only to `/home/USERNAME/public_html`.
- Keep `/home/USERNAME/mp-dashboard` private and deny directory listings.
- Use HTTPS, HSTS, secure cookies, database network restrictions, WAF/rate limits, and current PHP patches.
- Back up PostgreSQL and private document storage before migrations; test restoration.
