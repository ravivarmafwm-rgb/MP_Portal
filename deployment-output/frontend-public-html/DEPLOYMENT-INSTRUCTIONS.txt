HOSTINGER FRONTEND DEPLOYMENT

1. Delete or back up the old contents of the public_html directory for mpportal.focuswebmedia.in.
2. Upload the contents of this folder directly into that public_html directory. Do not upload the containing folder itself.
3. Confirm index.html is directly inside public_html.
4. Confirm .htaccess is directly inside public_html.
5. Confirm the assets directory is directly inside public_html.
6. Do not upload source files, src, node_modules, dist/server, or any other server output.

This is a client-only static SPA. It does not require Node.js, a process manager, SSR, a reverse proxy, or a changed document root.
